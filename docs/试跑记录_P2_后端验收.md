## 三、冻结时的参数基线（与契约第 2 节一致）

- 模型 glm-4.7，请求体带 `"thinking": {"type": "disabled"}`。
- 单次超时 60 秒；过载重试（429 / 1305）最多 3 次，间隔 3 秒、8 秒；超时与 5xx 重试 1 次，两类分开计数。
- 并发上限 1，串行队列。
- 跑题判定：正文领域术语命中数为 0 → 强制清零（主判据，算法侧确定性）；warnings 含「无关 / 跑题 / 不是数据结构」→ 同样清零（次判据）。
- evidence 校验：与正文做去空白后的原样子串匹配，失配降级 `low_confidence` 保留得分。
