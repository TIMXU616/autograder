# 需求文档（v1 · A 主驾在 9/20 晚定稿并冻结）

## 一、目标用户与场景

- 用户：高校计算机类实验课教师 / 助教
- 场景：批量接收学生实验报告 → 按统一评分点逐项核查 → 生成成绩与评语 → 反馈学生

## 二、功能清单（分两档，P1 结束冻结）

### 必须（MVP，P2 必须跑通）

| 编号 | 功能 | 验收标准 |
|---|---|---|
| M1 | 上传实验报告 | docx / pdf 可上传，格式与大小校验生效 |
| M2 | 选择评分点模板 | 可选模板，模板含评分项与分值 |
| M3 | AI 逐项核查评分 | 每个评分点输出得分 + 判定依据 |
| M4 | 评语生成 | 输出总评、亮点、改进建议 |
| M5 | 评阅结果展示 | 总分、逐项得分、评语完整可见 |
| M6 | 成绩列表 | 可查看历史评阅记录 |

### 加分（P3 视进度决定）

| 编号 | 功能 |
|---|---|
| P1 | 成绩导出 Excel |
| P2 | 成绩统计图表（平均分、分数段分布） |
| P3 | 批量上传与批量评阅 |
| P4 | 评分点模板自定义编辑 |

## 三、非目标（明确不做）

- 不做登录 / 权限体系（演示场景单人使用）
- 不做学生端交作业入口
- 不做真实的学校教务系统对接

## 四、评审得分策略对照

| 评分维度 | 分值 | 本项目的对应动作 |
|---|---|---|
| 技术创新性 | 30% | 评分点逐项核查 + 判定依据溯源（evidence 字段） |
| 工程完整性 | 25% | 前后端分层、接口文档、提交记录规范、README 可复现 |
| AI 工具使用 | 25% | 开发全程 LearnBuddy 对话留痕 + 产品内嵌大模型评分链路 |
| 用户体验 | 20% | 上传到结果的流程简洁、结果页信息层级清晰 |
