# LearnBuddy 对话记录归档

本目录存放开发过程中与 LearnBuddy 的真实对话记录，作为赛事要求的交付物之一。

> **重要**：这里只放**真实使用产生**的记录。不伪造、不拼接、不臆造。

## 归档规则

- 每个开发阶段一个文件，命名：`日期-环节.md`（如 `2026-09-21-架构设计.md`）
- 同一段对话的截图存为同名 `.png`
- 截图**要包含提问和回答的完整过程**，不要只截结论
