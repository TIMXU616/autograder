## 二、后端运行时：智谱 GLM API

后端运行时调用智谱 GLM API（OpenAI 兼容，base_url `https://open.bigmodel.cn/api/paas/v4`）。平台官方文档：`https://docs.bigmodel.cn/cn/api/rate-limit`。下表参数已于 2026-09-20 实测确认，依据见 `docs/试跑记录_GLM_API诊断.md`。

| 参数 | 取值 | 依据 |
| --- | --- | --- |
| 模型 | glm-4.7 | 免费档模型实测不可用，见下方禁用说明 |
| 思考模式 | 必须关闭：`"thinking": {"type": "disabled"}` | 开启时 reasoning_tokens 吃满 token 预算，正文为空 |
| 单次调用超时 | 60 秒 | 实测 2295 字输入 + 953 字输出耗时 8.1 秒 |
| 过载重试 | 遇 429 / 1305 退避重试，最多 3 次，间隔 3 秒、8 秒 | 实测平台过载频发，重试属必需 |
| 超时与 5xx 重试 | 1 次；仍失败该项置 failed（5002） | 与过载重试分开计数 |
| 并发评分上限 | 1（串行） | 实测并发 2 时一请求 429、一请求超时 |
| 队列等待超时 | 120 秒，超时任务置 failed（5005） | 与并发上限配套 |
| 上传接口超时 | 60 秒 | 20MB 本地上行 |
| 成本量级 | 单份报告一次评分约 2000 tokens | 实测 total_tokens=1988 |
| 官方错误码映射 | 智谱 1302（并发超限）、1305（过载）→ 我方 5001 | 智谱速率限制文档 |

禁用 glm-4.7-flash：它是推理模型，实测 `max_tokens=2048` 时 `reasoning_tokens=2038`、`content` 长度 0、`finish_reason=length`，单次耗时 105 秒；高峰期连续 429 / 1305，白天基本不可用。
备用模型链：主用 glm-4.7；应急备选 glm-4.5-flash（免费、质量达标，但实测 59.49 秒贴着超时线，启用时超时须放宽到 150 秒）；glm-4-flash 禁用（实测 total_score 与各项分之和差 11 分，违反契约自校验）。
额度口径：账号现金余额为 0，此前调用走赠送额度。**零成本路径：智谱对新用户完成实名认证后赠送 2000 万 Token 体验包（有效期 3 个月）**。本项目全周期用量约 20 万至 50 万 tokens（单份报告一次评阅约 2000 tokens），体验包足够覆盖，无需充值。额度耗尽后报 1113，表现为我方 5004，届时再考虑充值 10 元兜底。
费用口径：LearnBuddy 2500 积分由 A 统一控制在预算内。

## 三、稳定性实测结论

见 `docs/试跑记录_P1-02B_JSON稳定性.md`：JSON 三轮 3/3 合法、各项分数三轮全同（58/60）、evidence 全部命中原文子串。

API 侧实测见 `docs/试跑记录_GLM_API诊断.md`：glm-4.7 关闭思考后，2295 字输入 8.1 秒返回 953 字合法 JSON，6 个评分项齐全、evidence 6/6 命中原文、总分与各项之和一致，并正确识别出样本中的灌水段落。

保留条款：P1-02B 的稳定性测试在 LearnBuddy 对话层完成，与生产用的 glm-4.7 不是同一模型。P2 任务 6 完成模型调用封装后，必须用同一构造样本在新模型上重跑三轮，通过后才允许进入 prompt 定稿（任务 11）。

## 四、对接口契约的输入

1. consistency 语义定为：同一报告两次完整评阅的 total_score 之差绝对值，仅发生重新评阅时非空，未重评为 null。理由：实测 evidence 选择不稳定但分数稳定，一致性只能定义在分数层。
2. 5003（非法 JSON）的解析重试保留为保险条款，不因本次测试通过而移除。
3. evidence 子串校验的实现口径：与解析出的报告全文做原样子串匹配；失配时不判 fail，降级为 low_confidence 并在 warnings 记录。
