## 报告全文

《数据结构实验报告：单链表的实现与应用》

一、实验目的：掌握单链表的存储结构与基本操作，理解指针在动态内存分配中的作用，学会用单链表解决顺序存储不便插入删除的问题。

二、实验原理：单链表由若干节点构成，每个节点包含数据域和指向后继节点的指针域。头指针指向第一个节点，尾节点的指针域为空。插入和删除只需修改相邻节点的指针，在已定位的前提下时间复杂度为 O(1)；按序访问需要从头遍历，时间复杂度为 O(n)。

三、算法与实现：本实验用 C 语言实现。节点定义 struct Node { int data; struct Node* next; }。插入实现了头插法与尾插法两种，删除操作先遍历定位前驱节点再修改指针。关键代码（节选）：

Node* insert_tail(Node* head, int val) { Node* p = head; while (p->next) p = p->next; p->next = new_node(val); return head; }

链表逆置采用三指针迭代法，用 pre、cur、next 三个指针逐步翻转指向。

四、测试结果：构造含 10 个元素的链表，头插法插入后遍历输出顺序与插入顺序相反，符合预期。删除第 3 个节点后链表长度为 9。逆置操作循环执行 10000 次，valgrind 检测无内存泄漏。

五、结果分析：尾插法保持元素顺序但每次都要遍历到尾部，数据量大时应改用尾指针优化。删除头节点需要单独处理边界，本实现已覆盖该分支。异常情况：传入空链表时函数直接返回原指针，未出现崩溃。
