# frontend · 前端工程（B 负责）

技术栈：Vue 3 + Vite + Element Plus + Vue Router + Axios
（不引入 Pinia / TypeScript，8 天周期以"跑通 + 好看"为第一目标）

## 页面清单

| 路由 | 页面 | 关键交互 | 状态 |
|---|---|---|---|
| `/upload` | 上传报告 | 拖拽上传、格式与大小校验、选择评分模板、进度与轮询 | 待开发 |
| `/result/:id` | 评阅结果 | 总分、评分点逐项得分表格、评语、亮点与建议 | 待开发 |
| `/reports` | 成绩管理 | 列表、关键词/模板筛选、分页、跳转结果页 | 待开发 |
| `/templates` | 评分模板 | 模板卡片网格、评分点明细查看 | 待开发 |

## 开发约定

- 接口调用统一走 `src/api/index.js`，页面不直接写 `axios`
- `src/mock/` 下放 3 份假数据（评阅结果、成绩列表、模板列表），联调前页面吃 Mock
- 上传后评阅为异步：每 3 秒轮询一次状态，完成后跳结果页

## 启动

```bash
npm install
npm run dev
```
