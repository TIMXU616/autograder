# data · 数据与素材（C 负责）

## 1. reports/ 实验报告素材集

收集目标：**10 份以上**，覆盖面要全，用于测试评分链路与录制 Demo。

| 编号 | 文件名 | 格式 | 质量档位（好/中/差） | 学科 | 备注 |
|---|---|---|---|---|---|
| 01 | | docx | 好 | 数据结构 | |
| 02 | | pdf | 中 | 计算机网络 | |
| 03 | | docx | 差 | 操作系统 | |

要求：好、中、差三档各至少 3 份；至少 1 份扫描版 PDF（图片型，用于测解析失败兜底）。

## 2. seed/ 种子数据

数据库初始化用的评分点模板与演示数据。

## 3. cases/ 测试用例

`test-cases.xlsx`：正常上传、超 20MB、空报告、乱码、跑题、扫描版 PDF 等边界场景。

## 4. quality/ 质量抽检记录

`grading-quality-issues.md`：逐条记录 AI 评分的错判（哪份报告、哪个评分点、为什么错），反馈给 A 迭代提示词。

## 注意

上传的报告原件与数据库文件已加入 `.gitignore`，避免仓库体积过大；如需入库请只保留脱敏后的样例。
